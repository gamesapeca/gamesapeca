### 🛡️ About & Research Methodology

* 🎯 **Bug Bounty & Offensive Research:** Active on **HackerOne** and **Bugcrowd**, identifying complex zero-day and zero-prerequisite attack chains across enterprise infrastructure (Auth Bypasses, IDOR, WAF Evasion, SSRF, SSTI, Race Conditions, Memory Corruption).
* 🔬 **Static Analysis (SAST) & Semantic Engineering:** Developing custom AST parsers, taint tracking engines, and heuristic analyzers to detect high-impact flaws without generating false positives.
* ⚙️ **Binary & Mobile Reverse Engineering:** Deep reverse engineering of compiled binaries (ELF, PE, Mach-O), mobile apps (Android APK decompilation & native library hooking), and API protocols.
* ☁️ **Cloud & CI/CD Security (ASPM / CIEM):** Pioneer in ephemeral identity security (GitHub Actions OIDC token lifecycles, AWS IAM, GCP WIF, Azure Entra ID trust policies, and Kubernetes cluster security).
* 💻 **Open-Source Tool Author:** Creator of [`gha-oidc-auditor`](https://github.com/gamesapeca/gha-oidc-auditor), an official GitHub Marketplace Action for OIDC auditing and least-privilege Terraform HCL synthesis.
