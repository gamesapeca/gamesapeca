### About Me

* 🎯 **Bug Bounty & Offensive Research:** Active researcher hunting high-impact vulnerabilities across Web, API, and Cloud assets (IDOR, Authentication/Authorization Bypasses, WAF Evasion, SSRF, SSTI, Race Conditions, JWT/OIDC flaws).
* 🛡️ **Cloud & CI/CD Security (ASPM / CIEM):** Specializing in GitHub Actions OIDC token lifecycles, Workload Identity Federation (AWS IAM, GCP WIF, Azure Entra ID), and Kubernetes cluster vulnerability auditing.
* 💻 **Open-Source Tool Author:** Creator of [`gha-oidc-auditor`](https://github.com/gamesapeca/gha-oidc-auditor), an official GitHub Marketplace Action, static analyzer, least-privilege Terraform HCL synthesizer, and exploit chain generator for GitHub Actions OIDC.
* 🔍 **Research Scopes & Engagements:** Deep vulnerability research across enterprise scopes (OKX, DHL eCommerce, Slack, Doppler, Kubernetes, SimScale, Smart Contract audits).
